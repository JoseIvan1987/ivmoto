# Fotos de modelos

La app muestra una foto por modelo si encuentra el archivo en `app/src/main/assets/models/`.
Sin archivo usa la ilustración.

Nombres de archivo (formatos: webp, jpg, jpeg o png):

| Modelo | Archivo |
|---|---|
| 450 CL-C | `450clc` |
| 675 | `675` |
| 800NK | `800nk` |
| 800NK Advanced | `800nk_adv` |
| 800MT | `800mt` |
| 1000 MT-X | `1000mtx` |

Ejemplo: `app/src/main/assets/models/800mt.webp`.

Usa solo imágenes con permiso: fotos propias, de prensa autorizadas por el fabricante o con licencia.
Recomendado: ancho de unos 900 px, formato horizontal.
